# Heart-Disease-Prediction-SSL
End-to-end heart disease prediction pipeline: EDA → SimCLR self-supervised representation learning → fine-tuned PyTorch classifier → SHAP explainability. Trained on 1,190 samples with stratified split. Achieved 90.76% test accuracy and 0.936 ROC-AUC. Includes chi-square analysis, ROC, confusion matrix, and detailed feature importance.
The paper can be accessed using the DOI: 10.21203/rs.3.rs-7890495/v1 (https://doi.org/10.21203/rs.3.rs-7890495/v1).
